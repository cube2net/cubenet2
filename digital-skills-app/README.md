# تطبيق المهارات الرقمية - الصف السادس الابتدائي

تطبيق ويب عربي يعرض دروس المادة مقسّمة حسب الوحدات والدروس. كل درس يحتوي على:

- **ملخص الدرس**
- **شرح الدرس** مع نصوص وصور توضيحية
- **ورقة عمل** قابلة للطباعة
- **أسئلة للطلاب** (اختيار من متعدد وأسئلة مقالية) مع خيار لإظهار إجابات المعلم
- **عرض تقديمي للمعلم** بشرائح ورسومات توضيحية وملاحظات لكل شريحة

يعمل التطبيق داخل Docker على جهاز Proxmox المنزلي، ويُنشر على الإنترنت عبر **Cloudflare Tunnel** دون فتح أي منفذ في الراوتر.

## هيكل المشروع

```
server.js                 خادم Express (واجهات API وملفات الواجهة)
public/                   صفحات الواجهة (الفهرس، صفحة الدرس، التنسيق)
content/curriculum.json   الوحدات والدروس (الهيكل العام)
content/lessons/<id>.json محتوى كل درس: الملخص والشرح وورقة العمل والأسئلة
content/media/            الصور المستخدمة في الشرح
docker-compose.yml        التطبيق + نفق Cloudflare
```

## إضافة أو تعديل درس

1. أضف الدرس في `content/curriculum.json` داخل الوحدة المناسبة:
   ```json
   { "id": "u1-l2", "title": "عنوان الدرس" }
   ```
2. أنشئ `content/lessons/u1-l2.json` بالبنية التالية:
   ```json
   {
     "id": "u1-l2",
     "unit": "عنوان الوحدة",
     "title": "عنوان الدرس",
     "summary": "ملخص قصير",
     "explanation": [
       { "type": "text", "text": "فقرة شرح" },
       { "type": "image", "src": "/media/اسم-الصورة.png", "alt": "وصف الصورة", "caption": "تعليق" }
     ],
     "worksheet": { "title": "ورقة عمل", "name_line": true, "tasks": ["سؤال 1", "سؤال 2"] },
     "questions": [
       { "type": "mcq", "q": "سؤال", "options": ["أ", "ب", "ج"], "answer": 1 },
       { "type": "essay", "q": "سؤال مقالي", "answer": "إجابة نموذجية" }
     ]
   }
   ```
   `answer` في أسئلة الاختيار هو رقم الخيار الصحيح بدءًا من `0`.

   **المعادلات داخل النص العربي:** اكتبها بين علامتي `` ` `` مثل `` `=B2*C2` ``، فتظهر من اليسار إلى اليمين دون أن تنعكس رموزها وأرقامها.
3. ضع الصور في `content/media/`.

المجلد `content/` مُركَّب داخل الحاوية كقراءة فقط، فيكفي إعادة تحميل الصفحة بعد التعديل دون إعادة بناء الصورة.

## العرض التقديمي للمعلم

كل درس فيه مصفوفة `slides` يظهر له زر **«ابدأ العرض التقديمي»**، ويُفتح العرض على `/present.html?id=<id>`.

| الزر | الوظيفة |
|---|---|
| `←` أو المسافة أو `PageDown` | الشريحة التالية (وفي شرائح النشاط تُظهر الإجابات واحدة تلو الأخرى) |
| `→` أو `PageUp` | الشريحة السابقة |
| `N` | إظهار ملاحظات المعلم وإخفاؤها |
| `F` | ملء الشاشة |

تعمل الأزرار مع جهاز التحكم عن بُعد (Presenter Remote)، ومع السحب على الشاشات اللمسية.

### أنواع الشرائح (`layout`)

```json
{ "layout": "title",      "kicker": "...", "title": "...", "subtitle": "...", "visual": "hero", "notes": "..." }
{ "layout": "content",    "title": "...", "lead": "...", "bullets": ["..."], "aside": "...", "visual": "axes-cube" }
{ "layout": "question",   "kicker": "تهيئة", "title": "سؤال للنقاش", "visual": "flat-vs-solid" }
{ "layout": "visual",     "title": "...", "visual": "uses", "caption": "..." }
{ "layout": "definition", "title": "...", "definition": "...", "visual": "modeling-flow" }
{ "layout": "activity",   "kicker": "نشاط صفي", "title": "...", "items": [{ "q": "سؤال", "a": "إجابة" }], "hint": "..." }
{ "layout": "summary",    "title": "خلاصة الدرس", "bullets": ["..."], "closing": "في الدرس القادم: ..." }
```

`notes` في كل شريحة هي ملاحظات المعلم (ما يقوله ويسأله والوقت المقترح). ويمكن استخدام `"image": "/media/صورة.png"` بدل `visual`.

### الرسومات المدمجة

تُستخدم في الشرائح عبر `"visual": "<الاسم>"` وفي الشرح عبر `{ "type": "visual", "name": "<الاسم>", "caption": "..." }`:

`hero` · `flat-vs-solid` · `axes-cube` · `shape-pairs` · `modeling-flow` · `uses` · `design-workspace`

الرسومات مكتوبة بصيغة SVG في `public/visuals.js`، ويمكن إضافة رسومات جديدة للدروس القادمة بالطريقة نفسها.

## النشر على Proxmox عبر Docker

### 1. تجهيز الجهاز
أنشئ VM أو LXC على Proxmox (Ubuntu/Debian) وثبّت Docker وDocker Compose، ثم انسخ المجلد:

```bash
git clone https://github.com/cube2net/cubenet2.git
cd cubenet2/digital-skills-app
```

### 2. إنشاء نفق Cloudflare
1. ادخل إلى **Cloudflare Zero Trust** (`one.dash.cloudflare.com`).
2. اذهب إلى **Networks > Tunnels > Create a tunnel**، واختر **Cloudflared**.
3. أعطِ النفق اسمًا مثل `digital-skills`.
4. انسخ قيمة `TUNNEL_TOKEN` من أمر التثبيت الذي يعرضه Cloudflare.
5. في تبويب **Public Hostname** أضف:
   - **Subdomain:** `skills` (أو ما تريد)
   - **Domain:** نطاقك المسجّل في Cloudflare
   - **Service:** `HTTP` و **URL:** `app:3000`

   ملاحظة: الاسم `app` هو اسم الخدمة داخل docker-compose، ويعمل لأن النفق والتطبيق في الشبكة نفسها.

### 3. التشغيل
```bash
cp .env.example .env
nano .env                    # ضع TUNNEL_TOKEN الحقيقي
docker compose up -d --build
docker compose logs -f       # تأكد من ظهور "listening" واتصال النفق
```

الموقع يصبح متاحًا على `https://skills.نطاقك.com`. يمكن التحقق من التطبيق محليًا عبر `http://<عنوان-الجهاز>:3000/health`.

### 4. التحديث
```bash
git pull
docker compose up -d --build
```

## الأمان

- لا تُفتح أي منافذ من الراوتر إلى الإنترنت؛ الاتصال يبدأ من الجهاز نحو Cloudflare.
- ينبغي إضافة **Cloudflare Access** (سياسة حماية بالبريد) إذا أردت أن يدخل الطلاب بحساب معيّن، فالتطبيق الحالي عام للقراءة.
- ملف `.env` مستثنى من Git، ولا تشاركه.

## محتوى المنهج الحالي

17 درسًا في 7 وحدات، لكل درس ملخص وشرح مصوّر وورقة عمل وأسئلة وعرض تقديمي (160 شريحة إجمالًا):

| الفصل | الوحدة | الدروس |
|---|---|---|
| الأول | التصميم ثلاثي الأبعاد | مقدمة إلى النمذجة ثلاثية الأبعاد · معالجة الأشكال ثلاثية الأبعاد |
| الأول | جداول البيانات | تنفيذ العمليات الحسابية · المخططات البيانية |
| الأول | قواعد البيانات | مقدمة عن قواعد البيانات · إنشاء قاعدة بيانات · الفرز والتصفية |
| الثاني | التصميم المتقدم للمستندات | إنشاء الجداول وتنسيقها · تحرير الجداول |
| الثاني | تصميم المواقع الإلكترونية | تصميم صفحة إلكترونية · إضافة الصفحات* · نشر الموقع الإلكتروني |
| الثاني | تصميم ألعاب الحاسب | تخطيط وتصميم ألعاب الحاسب · برمجة ألعاب جهاز الحاسب |
| الثاني | المستشعرات في علم الروبوت | مستشعرات الروبوت · اتخاذ القرارات · إنشاء الخرائط |

\* عنوان غير مؤكد في المصادر المتاحة.

## ملاحظة عن المحتوى

عناوين الوحدات والدروس مأخوذة من مصادر تعليمية غير رسمية لكتاب 1447هـ، والمحتوى مسودات صيغت من المفاهيم العامة لكل درس، ولذلك تحمل كل الدروس حالة «مسودة». طابق كل درس مع كتاب الطالب ومنصة مدرستي قبل استخدامه مع الطلاب، ثم غيّر `"status"` إلى `"ready"` في الدرس وفي `content/curriculum.json`.
