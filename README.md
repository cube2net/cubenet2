# ثيم كيوب نت لمتجر سلة

ثيم عربي متجاوب مبني على **Salla Twilight**. يستخدم واجهات سلة الأصلية للمنتجات والتصنيفات والبحث والحساب والسلة والدفع؛ لا ينشئ كتالوجًا أو مخزونًا منفصلًا.

يعرض عنصر المقدمة «كيوب نت» ويمكن تعديل نصوصه وصورته وروابطه من إعدادات مكونات الصفحة الرئيسية في سلة. شعار المتجر يبقى قابلًا للتعديل من إعدادات سلة.

## الملفات

- `twilight.json` — تعريف الثيم ومكون المقدمة.
- `src/` — قوالب Twig وأوراق الأنماط وموارد التصميم.
- `public/` — ملفات الواجهة المنشأة عند بناء الثيم.
- `INSTALL-AR.md` — خطوات البناء والربط مع حساب سلة.
- `NOTICE.md` و`LICENSE` — مصدر القالب وشروط الترخيص.

عند رفع الملفات إلى GitHub، يجب أن يكون `twilight.json` و`src/views/pages/index.twig` في جذر المستودع مباشرةً، من دون مجلد `cubenet-salla-theme` يحيط بهما. ابدأ بدليل `INSTALL-AR.md`. يحتاج الربط والمعاينة داخل سلة إلى مستودع GitHub وحساب سلة الشركاء.
